# EvBox 工具箱 · 安装包分发

本仓库**只做分发**，存放 EvBox 工具箱的手环快应用安装包（`.rpk`）。
源码仓库是私有的，源码与构建脚本不在本仓库中。

## 下载

打开本仓库的 [Releases](https://github.com/guomengtao/evbox-dist/releases)，下载最新版本对应的 `.rpk` 文件。

当前最新：**v1.0.57**（versionCode 58）

| 文件 | 适用 |
|---|---|
| `com.application.watch.evbox.release.1.0.57.rpk` | 手环通用（首发面向手环9 Pro 方屏） |

## 安装

1. 下载上表中的 `.rpk`
2. 用手机端工具把它装到手环（与其它手环快应用的安装方式一致）
3. 覆盖安装即可，无需卸载旧版

## 关于这个应用

EvBox 工具箱是一款手环快应用，把常用小工具塞进手环：抬腕就能看倒数日、查农历、算数、出二维码，不用掏手机。

- 包名：`com.application.watch.evbox`
- 平台：`watch`
- 功能：倒数日（公历/农历双轨、重复提醒、钉首页）、农历黄历、计算器、二维码、一言、答案之书、震动实验室、数据备份、中文输入
